# CHANGE-LOG · mini-child-code-project

> **规矩**：任何改动都要在这里留一行，否则 `.githooks/pre-commit` 拒绝提交（无跳过开关）。
> **格式**：新记录加在表格**最上方**。一条记录 = 一次 git 提交。
> **范围**：只记本项目自己的事。🔴 **父项目的索引表变化记在父项目，不是这里。**
