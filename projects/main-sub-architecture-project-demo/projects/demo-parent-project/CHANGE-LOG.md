# CHANGE-LOG · demo-parent-project

> **规矩**：任何改动都要在这里留一行，否则 `.githooks/pre-commit` 拒绝提交（无跳过开关）。
> **格式**：新记录加在表格**最上方**。一条记录 = 一次 git 提交。
> **范围**：🔴 **只记父级的事。** 子项目内部的改动记在子项目自己的 CHANGE-LOG 里，不往上冒泡——
> 子项目根本不在本仓库的提交范围内（`projects/` 被 `.gitignore` 排除），硬记就是假历史。
