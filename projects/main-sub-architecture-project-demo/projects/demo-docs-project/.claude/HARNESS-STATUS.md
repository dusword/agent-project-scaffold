## 确立时特别记下的一条

⚠️ `pre-commit` 的 README 同步强制**只覆盖 `docs/` 和 `projects/`**，
而本项目的内容在 `inbox/` 和 `archive/`。**这两个目录的索引同步靠纪律，不是靠钩子。**

当时讨论过是否改钩子把 `inbox/`、`archive/` 也纳入强制，结论是**不改**：
钩子是从模板继承的通用件，为一个项目改它会导致各项目的钩子分叉，以后没法统一升级。
代价是这条靠自觉——已写进宪法第 4 条，并在本文件留档提醒。
