# 01 · 需求

> 这份文档示范「代码项目」该有的需求文档长什么样：**微型但完整**——
> 目标 / 功能清单 / 边界三段齐全，每条都能验收。
> 篇幅不重要，**能不能照着它判断「做完了没有」才重要。**

---

## 1. 目标

给命令行用户一个**不用联网、不用查表**的单位换算工具。

一句话验收标准：**任何人在终端敲一行命令，能立刻得到换算结果，不需要看文档。**

### 为什么要做

日常在终端里干活时，遇到英制/公制混用（尤其是 inch 与 cm、lb 与 kg），
现有做法是切到浏览器搜一下——打断心流，而且搜索结果的精度和口径不稳定。

---

## 2. 功能清单

| # | 功能 | 验收方式 |
|---|---|---|
| F1 | 长度换算（mm / cm / m / km / inch / foot / mile） | `convert 1 mile km` → `1.6093 km` |
| F2 | 重量换算（g / kg / ton / oz / lb） | `convert 1 lb g` → `453.5924 g` |
| F3 | 温度换算（摄氏 c / 华氏 f / 开尔文 k） | `convert 100 c f` → `212.0 f` |
| F4 | 单位大小写与前后空白不敏感 | `convert 1 " KM " M` 与 `convert 1 km m` 结果一致 |
| F5 | 列出所有支持的单位 | `convert --list` 按量纲分组打印 |
| F6 | 控制结果小数位 | `convert 1 mile km --digits 2` → `1.61 km` |
| F7 | 错误说人话 + 退出码可判 | 见下表 |

### F7 的错误约定

| 情况 | 输出（stderr） | 退出码 |
|---|---|---|
| 数值不是数字 | `错误：'abc' 不是一个数字` | 1 |
| 单位不认识 | `错误：不认识的单位 'xxx'。用 --list 看支持哪些。` | 1 |
| 量纲对不上（如 kg → m） | `错误：kg 与 m 不是同一量纲。同一量纲之间才能换算。` | 1 |
| 参数个数不对 | 用法提示 + `错误：需要三个参数 —— 数值 源单位 目标单位` | 1 |
| 成功 | 结果打到 stdout | 0 |

🔴 **退出码是需求的一部分，不是实现细节**——它要被 shell 脚本判断。

---

## 3. 边界（明确不做）

写清楚不做什么，和写清楚做什么一样重要。**下面这些如果有人提，先回来改这份文档，不要直接开做。**

| 不做 | 理由 |
|---|---|
| 货币换算 | 汇率是时变数据，需要联网与数据源，属于另一个项目 |
| 面积 / 体积 / 速度等复合量纲 | 第一版先把三个基础量纲做扎实；复合量纲的换算表结构不同，会污染现在的设计 |
| 交互式 REPL 模式 | 一次一换算已经够用；REPL 会引入状态管理，收益不抵复杂度 |
| 图形界面 | 目标用户是终端用户 |
| 换算历史记录 | 需要落盘，引入路径与权限问题，第一版不碰 IO |
| 精度可配置到超过 float 能力 | 用 Python float 即可；要更高精度是另一个量级的需求（Decimal 全链路改造） |
