# CHANGE-LOG · main-sub-architecture-project-demo

> **规矩**：任何改动都要在这里留一行，否则 `.githooks/pre-commit` 拒绝提交（无跳过开关）。
> **格式**：新记录加在表格**最上方**。一条记录 = 一次 git 提交，`git log --oneline` 应与本表对得上号。
> **范围**：只记本项目自己的事。🔴 **子项目的变化记在子项目自己的 CHANGE-LOG 里，不往上冒泡。**
